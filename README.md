# AOSStudio SDK Platform

AOSStudio SDK Platform provides the public API and framework resources for compiling apps against Android 17, API 37.0. The SDK platform package installs as `platforms;android-37.0`. A separate System API stubs archive supports builds that need those APIs, such as WebView.

The terms in [LICENSE](LICENSE) cover the project's build scripts, workflows, documentation, and verification fixtures. Upstream components retain their respective licenses and notices.
